# Third-party dependencies

This repository uses dependencies installed separately through pip:

- PyQt5 / Qt: https://www.riverbankcomputing.com/software/pyqt/
- NumPy: https://numpy.org/
- SciPy: https://scipy.org/
- pandas: https://pandas.pydata.org/
- Matplotlib: https://matplotlib.org/
- Pillow: https://python-pillow.github.io/
- openpyxl: https://openpyxl.readthedocs.io/
- xlrd: https://xlrd.readthedocs.io/
- PyInstaller (optional build tool): https://pyinstaller.org/

Each dependency retains its own license. Packaging must preserve the applicable third-party notices.
