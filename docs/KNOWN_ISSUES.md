# 已知问题（首次公开版本）

本次公开整理集中于脱敏、发布范围和运行说明，尚未修复以下既有计算问题。

## 优先处理

1. 自动寻优路径仅扣除空白，没有应用稀释倍数；倍数不为 1 时，与手动计算及报告解释可能不一致。
2. 直线、二次、4PL、Logit-Log 接收权重参数，但当前实现没有应用这些权重。
3. 拟合失败后可能仍保留上一次结果，导出前需核对当前拟合状态。

## 其他限制

- 上述基础模型尚未完整填充 V3 的求值函数、区间、SE/AIC 字段，部分分析工具会失败，默认统计值不能当作有效估计。
- “1/标准差²”采用所有 Y 的整体标准差，产生常数权重，并非逐浓度复孔权重。
- 通用数值反推会漏掉搜索区间右端点的精确解；多根和切触根仍需完善。
- 部分模型在绘制范围内可能产生非有限值和 RuntimeWarning。
- 4PL 的 a/d 渐近线文字标签可能与拟合方向不一致。
- 高 R² 不代表模型适合定量，也不能替代标准品回算和独立验证。
- Windows 7、32 位系统及其他操作系统未在此次公开准备中验证。

后续应先修复结果一致性，再增加针对边界和导出结果的回归验证。
